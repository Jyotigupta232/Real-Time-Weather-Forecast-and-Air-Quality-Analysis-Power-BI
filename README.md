Real-Time Weather Forecast and Air Quality Analysis | Power BI

Project Overview:
This project presents an interactive Power BI dashboard that analyzes real-time weather conditions and air quality data using live REST API integration. The dashboard visualizes important environmental metrics such as temperature, humidity, wind speed, 7-day weather forecasts, Air Quality Index (AQI), and pollution components.

The goal of this project is to transform live environmental data into meaningful visual insights that help users easily understand weather trends and air quality conditions.

Objectives:
1.Fetch real-time weather data using a REST API
2.Transform and clean API data using Power Query
3.Visualize environmental metrics using interactive dashboards
4.Provide insights into weather conditions and air quality levels
